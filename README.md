# 👩‍💼 Employee Management System

A Java-based web application to manage employees, projects, and clients in an organization.  
Built using **Java EE (JSP, Servlets, JDBC)** with an MVC architecture. It includes secure OTP-based login, admin dashboard, and automated ID generation.

---

## 🛠 Technologies Used

- **Java 8**
- **JSP / Servlets**
- **JDBC**
- **Hibernate**
- **Spring MVC (optional, if used)**
- **MySQL**
- **HTML, CSS**
- **Maven**
- **Eclipse IDE**
- **Apache Tomcat**
- **Git & GitHub**

---

## 🔐 Key Features

- **Admin Dashboard**:
  - Add, update, delete employees
  - Add, update, delete projects
  - Add, update, delete clients
  - Assign/release employees to/from projects
  - View employees on the bench (unassigned)
  - Track project assignment history

- **OTP-Based Login** (for Clients & Employees):
  - 6-digit OTP sent via email
  - Max 5 failed attempts → account banned for 5 minutes

- **Auto ID Generation**:
  - Employees: `JTC-001`, `JTC-002` ...
  - Projects: `project-001`, `project-002` ...
  - Clients: `client-001`, `client-002` ...

- **Contact Management**:
  - Multiple contact persons per client
